# 卫星图标说明

## 需要手动添加的文件

请将 `satellite-icon.svg` 转换为 PNG 格式的图片:

1. 使用在线工具或设计软件将 `satellite-icon.svg` 转换为 PNG
2. 建议尺寸: 120x120 像素 (或更高分辨率如 240x240)
3. 保存为: `miniprogram/images/satellite.png`

## 转换方法

### 方法1: 在线转换
- 访问 https://cloudconvert.com/svg-to-png
- 上传 satellite-icon.svg
- 设置尺寸为 120x120 或 240x240
- 下载转换后的 PNG 文件

### 方法2: 使用 Figma/Sketch/Illustrator
- 在设计软件中打开 SVG
- 导出为 PNG 格式
- 设置合适的分辨率

### 方法3: 使用在线 SVG 编辑器
- 访问 https://www.vectorpaint.net/
- 导入 SVG
- 导出为 PNG

## 临时解决方案

如果暂时没有 PNG 图片,可以:
1. 使用占位图标
2. 或者直接使用 emoji: 🛰️
3. 代码中已经设置了路径: `/images/satellite.png`
